# Tools - GNOME Developer Documentation

# Tools ¶

When developing applications and system components for GNOME, you’ll likely need
to rely on various tools outside of your editor.

- GTK Inspector : inspect GTK applications
- Valgrind : a tool that allows to track memory related
errors in C and C++ programs
- Massif : a heap profiler, part of the Valgrind suite
- Sysprof : a system-wide sampling profiler that uses the
perf Linux kernel module
